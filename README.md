# Посмотри в окно

Учебный проект «Посмотри в окно» для Яндекс Практикума (спринт 3: «Вёрстка. Доступность и подходы к организации стилей»).

## Описание

Приложение для просмотра видео с видами из разных городов и в разное время суток. Реализованы лейаут секций, типографика, кастомные элементы формы (поле ввода города, чекбоксы времени суток, кнопки), интерактивные состояния (`:hover`, `:active`, `:focus`, `:focus-visible`, `:has(:focus-visible)`), доступность (`.visually-hidden`, контрастность, работа с клавиатуры) и позиционирование прелоадера и блока ошибок.

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, псевдоклассы и псевдоэлементы, кастомные чекбоксы)
